# Designer UI implementation specification

The approved direction is a quiet dark studio: three columns (256 px Pages/Instruments/Layers, flexible canvas, 320 px scoped inspector), 64 px header, compact simulation footer. Teal identifies selection and primary actions; surfaces and typography provide hierarchy. System UI typography is separate from the unchanged canvas fonts.

Basic sketch: project/title + saved | Basic--Advanced--Expert | Undo Redo Preview Export. Pages on the left; canvas in the middle; selected Number has Content (Reading, Caption, Text size) and Appearance (Accent, five preview presets). No selection shows an invitation plus Theme style / Page background actions. Extra controls live in explicit menus/sheets.

Advanced sketch: same geometry, coordinates/alignment/grouping accessible, independent typography and effect intensity, gradient/texture controls. Expert sketch: same navigation, complete style measurements, manual scales, overlap exemptions and vehicle calculations. Phone sketch: compact header, canvas, simulation, Tools/Properties buttons; one focus-managed sheet at a time with 44 px targets.

Review: the gauges, not surrounding chrome, carry visual personality. No decorative racing textures in the editor, no repeated From theme rows, no four permanent sidebars. Controls are discovered by task and selection. Every level changes only presentation and retains custom document values.

Implementation review: Basic uses one grouped appearance chooser and a value color for Number, since its plain variant has no visible accent geometry. Advanced offers separate typography and palette controls. Expert reveals exact effects in a dedicated section. Phone uses one scroll-contained sheet with a compact two-row header. Reviewed screenshots and test results are recorded in [UI acceptance](designer-acceptance/ui-redesign-2026-11-06.md); the editor guide lists relocated controls.

Design references: [Penpot's interface](https://help.penpot.dev/user-guide/first-steps/the-interface/), [Grafana panel editing](https://grafana.com/docs/grafana/latest/visualizations/panels-visualizations/panel-editor-overview/), [SimHub Dash Studio](https://github.com/SHWotever/SimHub/wiki/Dash-Studio-Editor-Overview), [progressive disclosure](https://www.nngroup.com/articles/progressive-disclosure/), [Frontend Design skill](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md), [Web Design Guidelines skill](https://github.com/vercel-labs/agent-skills/blob/main/skills/web-design-guidelines/SKILL.md) and the [W3C slider pattern](https://www.w3.org/WAI/ARIA/apg/patterns/slider/). These informed visual hierarchy, selection-specific properties, disclosure, native controls, keyboard/focus behavior and reduced motion; they introduce no runtime dependencies.
