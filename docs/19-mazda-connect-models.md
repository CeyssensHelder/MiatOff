# Mazda Connect 6G by model and market

MiatOff uses the original Mazda Connect (MZD Connect or 6G). Mazda uses the Mazda Connect name for several generations.
Use the country of original sale, model year or build date, and trim to identify a candidate. The actual unit's
version and the file hashes from **Check your car** determine which installer actions can run. The models below
are research candidates for MiatOff. The Mazda3 and CX-5 presets have been exercised in simulation.

## North America

Mazda North American Operations' bulletin covers the following vehicles when equipped with the applicable Mazda
Connect system. The bulletin specifies software 74.00.324 or later.

| Model | Coverage in bulletin 09-018/22b |
|---|---|
| Mazda2 (DJ/DL) | 2016–2023 Mexico spec |
| Mazda3 (BM/BN) | 2014–2018 |
| Mazda6 (GJ/GL) | 2016–2021 |
| CX-3 (DK) | 2016–2021, plus 2022–2023 Mexico spec |
| CX-5 (KE/KF) | 2016–2020, plus 2021 Canada/Mexico spec and 2022–2023 Mexico spec |
| CX-9 (TC) | 2016–2020, plus 2021 Canada/Mexico spec below the bulletin's VIN cutoff and 2022–2023 Mexico spec |
| MX-5 (ND) | 2016–2023 |

[Mazda bulletin 09-018/22b, applicability and version](https://static.nhtsa.gov/odi/tsbs/2022/MC-10226834-0001.pdf)

- **Canada.** The CX-5 and CX-9 received the newer infotainment at the 2021.5 midyear update. [Mazda Canada announcement](https://en.media.mazda.ca/2021-05-12-CX-5-and-CX-9-Receive-Mid-Year-Updates-with-New-2021-5-Models)
- **Mexico.** Mazda lists the 6G manual for Mazda2 sedan (2019–2026) and hatchback (2017–2026), and CX-3 (2017–2026). The manual index identifies the generation. Later model years still need an exact firmware check. [Mazda Mexico owner manuals](https://www.mazda.mx/servicio-mazda/tu-mazda/manuales-de-propietario)
- **US.** Mazda lists the 2019 Mazda3, 2020 CX-30, and 2021 CX-5 and CX-9 under its newer Mazda Connect service guidance. [Mazda service alert SA-003/24](https://static.nhtsa.gov/odi/tsbs/2024/MC-11006995-0001.pdf)
